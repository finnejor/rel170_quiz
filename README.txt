Quiz i REL170 for balistudentene, våren 2026

Åpne index.html i en nettleser for å teste lokalt.

Filstruktur:
- index.html: selve siden
- styles.css: utseende
- app.js: quizlogikk og lokal progresjon
- data/questions.js: alle spørsmål og fasit

Løsningen bruker ikke innlogging og sender ikke data til en server. Progresjon lagres lokalt i studentens egen nettleser med localStorage.

For publisering kan hele mappen lastes opp til et webhotell, Netlify, GitHub Pages eller tilsvarende. Lenken kan deretter deles i sosiale medier.
